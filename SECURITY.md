# Security policy

Report suspected vulnerabilities using GitHub’s private reporting form. Include the
affected relflow version, platform, configuration, observed behavior, and impact.
Redact credentials and personal data from any logs or sample inputs you share.
[Report a vulnerability](https://github.com/relflow/relflow/security/advisories/new)

Use the issue tracker for ordinary bugs and feature requests.
[Open an issue](https://github.com/relflow/relflow/issues/new/choose)
