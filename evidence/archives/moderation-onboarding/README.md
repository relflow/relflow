# Archived moderation onboarding example

This preserves the synthetic moderation tutorial retired with the Quarto site.
Its recorded run demonstrates an API workflow; it does not establish real-world
moderation quality or comparative model performance.

`moderation.zip` contains the complete original example: the Python source,
README, training and validation fixtures, prediction requests, and recorded run.
Each ZIP member was checked byte-for-byte against the unpacked original before
the old documentation files were removed. `recorded-run.json` is also retained
separately, unchanged, for inspection.

The example's install command pins relflow source revision
`dc64b85d75a85b3cef8ceada1869ee512f2fbe65`. The receipt records its original
settings, versions, fixture hashes, and predictions. These are historical
artifacts; the current documentation build does not execute them.
