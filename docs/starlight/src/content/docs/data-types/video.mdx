Use `rf.Video` when inspection footage, camera clips, or product videos should help predict another field. Each video supplies one vector. The rest of the model learns how much that visual and temporal evidence matters for the task.

<DataTypePage name="Video">

## Input values

Supply one path per video, such as `"/mnt/footage/42.mp4"` or `"s3://recordings/clips/42.webm"`. Use `base` to resolve relative names such as `"42.mp4"` against a directory or object-store prefix. Train and predict in environments with access to those files. Use a repeated [Branch](/concepts/branches/) for a sequence of video clips.

A null value takes the null field state and costs no video read. An empty path, a missing file, an audio-only container, and unreadable video data raise errors. Install the [video extra](/installation/#optional-dependencies) and provision the encoder on each training or prediction host.

## Standardization and processor pipelines

PyAV decodes MP4, MOV, WebM, MKV, AVI, and other FFmpeg-supported containers and codecs (including H.264, HEVC, MPEG-4, VP8, VP9, AV1, and MJPEG) from local paths and remote streams. Display-rotation metadata (`DISPLAYMATRIX`) rotates coded frames to upright RGB before preprocessing, and containers missing duration metadata fall back to a lightweight packet-timestamp scan without decoding every frame.

`offset` skips leading seconds and `duration` bounds the span analyzed per file. With `window=None` (the default), the field samples `num_frames` frames at evenly spaced bin midpoints across the selected span. Setting `window` enables temporal chunking: videos longer than `window` use `clip="chunks"` by default, averaging embeddings for up to `max_windows` windows into one deterministic vector. `clip="head"`, `"center"`, and `"tail"` sample a single window. Keyframe seeking jumps across long gaps so sparse sampling avoids decoding untouched segments.

The default [X-CLIP base encoder](https://huggingface.co/microsoft/xclip-base-patch32) unwraps its video tower (vision encoder, visual projection, and multiframe integration transformer) without loading its text encoder into model inference. VideoMAE, V-JEPA 2, ViViT, and TimeSformer checkpoints are also supported without custom code execution or `torchvision`. Fixed-frame encoders reject an explicit `num_frames` that differs from their native capacity, and V-JEPA 2 requires `num_frames` to be a multiple of `tubelet_size`. To analyze a long video with a fixed-frame checkpoint, leave `num_frames=None` and configure `window`, `stride`, and `max_windows` with `clip="chunks"`.

On a cold cache, a bounded thread pool decodes, orients, and preprocesses distinct videos while the frozen encoder processes clip batches on the model device. The cache stores the pristine vector before the learned projection or training jitter. Fields sharing the same video version, temporal sampling settings, processor configuration, encoder weights, and execution precision reuse that vector across epochs and runs sharing a store.

Training with automatic precision uses BF16 mixed precision on supported CUDA devices. For direct prediction on a CUDA model, `with torch.autocast("cuda", dtype=torch.bfloat16):` selects BF16. Warm the cache under the same precision as prediction.

Ordinary local paths are checked against file identity, size, and timestamps. Mutable object-store URIs read the object once per lookup to compute its SHA-256 digest and decode that same download on a cold miss. For content-addressed object names, set `immutable=True` so warm hits make zero storage requests. On a cold read, seekable object stores can fetch just the byte ranges needed for container headers and keyframe seeks.

### Pin the encoder for deployment

To use the same X-CLIP weights and processor in training and serving, download a specific revision when preparing your deployment. This example fetches the three files relflow needs from the [pinned X-CLIP revision](https://huggingface.co/microsoft/xclip-base-patch32/tree/a2e27a78a2b5d802e894b8a1ef14f3a8ce490963).

```python
from huggingface_hub import snapshot_download

snapshot_download(
    repo_id="microsoft/xclip-base-patch32",
    revision="a2e27a78a2b5d802e894b8a1ef14f3a8ce490963",
    allow_patterns=["config.json", "preprocessor_config.json", "model.safetensors"],
    local_dir="./models/xclip-base-patch32-a2e27a7",
)
```

Ship that directory with your application and point the video field at it. Each host can then load the encoder offline from the same path relative to its working directory.

```python
import relflow as rf

footage = rf.Video(model="./models/xclip-base-patch32-a2e27a7")
```

## How is this leaf trained?

Downstream targets train a field-specific projection into the model's representation space while the pretrained video encoder remains frozen. A reconstructing mask adds state classification and an L1 or L2 objective against the pristine video vector. Jitter applies only to eligible training inputs.

### Predictions

A video field ordinarily provides context for other predictions. Set `embed=True` to export its learned representation in the `representations` column. A video reconstruction objective predicts a vector internally.

## Leaf-specific parameters

```python
import relflow as rf

class Inspection(rf.Model):
    footage = rf.Video(base="s3://footage/by-digest/", immutable=True, window=4.0, max_windows=6)
    defect = rf.Boolean(mask=True)

model = Inspection(preset="small")
```

| Option | Default | Purpose |
| --- | --- | --- |
| `model` | `"microsoft/xclip-base-patch32"` | Select a compatible Hugging Face video encoder and processor, or their local directory. |
| `base` | `None` | Resolve relative file names against this directory or URI prefix. Relative local names otherwise use the working directory. |
| `immutable` | `False` | Treat each resolved path as a permanent identity for a single version of the bytes. |
| `offset` | `0.0` | Skip this many leading seconds before selecting clips. |
| `duration` | `None` | Cap the span in seconds analyzed after `offset`. `None` uses the remainder of the video. |
| `window` | `None` | Set the temporal window length in seconds. `None` samples `num_frames` frames uniformly across the full selected span. |
| `stride` | `None` | Set the hop in seconds between windows when `window` is set and `clip="chunks"`. `None` uses half of `window`. |
| `max_windows` | `4` | Cap the number of windows averaged per video when `window` is set and `clip="chunks"`. When exceeded, windows are spaced evenly across the span. A cap of one selects the center. |
| `clip` | `"chunks"` | Choose `"chunks"`, `"head"`, `"center"`, or `"tail"` when `window` is set and the span exceeds `window`. |
| `num_frames` | `None` | Frames sampled uniformly per window. `None` uses the checkpoint's native frame count, or 8 when undeclared. |
| `encoder_pooling` | `"auto"` | Choose `"auto"`, `"mean"`, `"cls"`, or `"pooler"` over encoder outputs. |
| `read_workers` | `4` | Bound concurrent reads, decoding, and frame preprocessing per encoder process. |
| `encoder_batch_size` | `8` | Bound the number of video clips in one encoder call. |
| `cache` | `True` | Enable automatic reuse. A positive integer also caps hot entries. `False` disables the cache tiers. |
| `store` | `None` | Choose the local cache directory. The default honors `RELFLOW_CACHE_DIR` and otherwise uses the platform cache. |
| `memory` | `None` | Set the shared RAM budget in MiB. The default is 64 MiB. |
| `resident` | `None` | Set the device table budget in MiB. CUDA defaults to one eighth of free memory up to 512 MiB. Other devices default to zero. |
| `objective` | `"l2"` | Choose `"l1"` or `"l2"` coordinate error for a reconstruction objective. |
| `jitter` | `rf.Jitter()` | Perturb pooled video vectors during training. |

### Request methods

To prepare a cache ahead of training, call `model.nodes["/footage"].embedder.warm(paths)` with a file name or a sequence of file names on the intended device and precision.

## Errors raised

A failed read, missing video stream, or unsupported codec identifies the affected path and field address. Setting `offset` at or past the end of the video, passing an incompatible `num_frames` for a fixed-frame checkpoint, or passing a 2D image-only processor raises a `ValueError`. A local file that changes between selection and cold decoding raises an error so the batch can be encoded again.

### Footguns

- **Sampling only a few frames across an hour-long video with `window=None`.** Uniform whole-video sampling can miss brief localized events. Set `offset`/`duration` to focus on the relevant interval, or set `window` with `clip="chunks"` and `max_windows` to cover multiple segments.
- **Reusing a mutable filename with `immutable=True`.** Training can reuse an earlier video even after its bytes change. Use distinct names per version or keep the default freshness policy. See [input values](#input-values).
- **Serving paths supplied by callers.** The prediction process opens those paths with its storage access. Validate references at the application boundary and scope storage permissions to your media collection. See [HTTP serving](/advanced/inference-and-deployment/).
