Use `rf.Text` for messages, descriptions, and other prose whose meaning should
help a prediction. A frozen text encoder turns each string into a vector;
relflow learns how to use that vector alongside the rest of the record.

<DataTypePage name="Text">

## Input values

Pass the text itself in the matching field, such as
`"I was charged twice for the same order."`. You do not need to prepare token IDs
or embeddings yourself.

A null string has a separate state. An empty string is still a supplied text
value and is processed by the tokenizer.

Install the [`text` extra](/installation/#optional-dependencies) before constructing a model that uses this field.

The default encoder is `sentence-transformers/all-MiniLM-L6-v2`. It averages
attended token vectors into a 384-dimensional representation. The first use can
download the encoder and tokenizer. Set `model` to a compatible Hugging Face model name or a local
model directory to choose another encoder. [MiniLM model card](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)

## Standardization and processor pipelines

The tokenizer truncates each supplied string to `max_length` tokens.
A frozen encoder produces token vectors; `encoder_pooling` selects the
string-level vector. By default, each pooled vector is scaled to unit root mean
square (RMS) before training jitter and the field’s learned projection. This
preserves direction and gives encoders with different output magnitudes a
common input scale. Set `encoder_rms=False` to use the original magnitudes.
The projection combines the result with the field’s state embedding.

The text encoder stays frozen. Training jitter perturbs the pooled input
representation after pristine frozen vectors have been prepared, while
reconstruction targets retain the pristine vectors.

Caching is automatic across training, validation, and prediction. Loader workers
send compact text IDs to a shared local cache; tokenization and frozen encoding
are reused when their inputs and settings match. Fields can share frozen
vectors while retaining their own learned task projections.

SQLite stores the attended token IDs as variable-length int32 records and
restores the tokenizer’s exact IDs and attention mask when needed. The compact
format has its own namespace and warms as strings are encountered.

The frozen encoder runs in float32 on CPU, including during mixed-precision
training. On accelerators it uses the checkpoint and trainer precision.
`rf.Model.load(path)` restores an older checkpoint’s encoder, pooling, and
projection scale. Use the loaded model when resuming an older training run.

The cache distinguishes encoder weights, tokenizer configuration, pooling,
device type, and precision. It stores pristine values before training jitter,
independently of task labels. RAM and device hot entries are bounded; disk
entries persist across runs without a built-in size limit. A configured
`store` controls their location; it is not required to enable persistence.

Use `cache=4096` for an additional hot-entry cap, or `cache=False` to tokenize
and encode directly without any cache tier. Fields sharing one directory within
a process must use the same `memory` and hot-entry cap settings. The saved model
retains the configuration, while encoder assets and cached data remain external
runtime resources.

## How is this leaf trained?

A reconstruction objective trains a decoder against the pristine frozen encoder vector:
mean squared coordinate error for `objective="l2"`, or mean absolute coordinate
error for `"l1"`.

Downstream targets train the field’s task projection while the pretrained
encoder remains frozen. Reconstruction predicts a vector, not token IDs,
strings, or a generated completion.

### Predictions

A text input can support [Boolean](/data-types/boolean/),
[categorical](/data-types/category/), or [numeric](/data-types/number/) answers
elsewhere in the schema.

`embed=True` exports the field's learned representation in the prediction
table's `representations` column. It does not create a training objective.

With `task=rf.reconstruct(...)`, `Text` trains against the frozen encoder's vector,
using `objective="l2"` by default or `"l1"`. This is representation
reconstruction; the field does not produce generated strings or completions.

## Leaf-specific parameters

```python
message = rf.Text(
    max_length=256,
    tokenizer_batch_size=4096,
    encoder_batch_size=32,
    store="./text-vectors",
    memory=64,
    resident=256,
)
```

| Option | Default | Purpose |
| --- | --- | --- |
| `model` | `"sentence-transformers/all-MiniLM-L6-v2"` | Select the frozen encoder by Hugging Face model name or local directory. |
| `max_length` | `128` | Bound tokenized length, including special tokens. Longer text is truncated. |
| `tokenizer_batch_size` | `4096` | Bound the number of strings prepared in one tokenizer call, independently of encoder batches. |
| `encoder_batch_size` | `32` | Bound the number of strings encoded together. Reduce it if encoding uses too much memory. |
| `encoder_pooling` | `"mean"` for the default MiniLM, `"cls"` for other model IDs | Select masked mean, first token, or the encoder’s `"pooler"` output. |
| `encoder_rms` | `True` | Scale each pooled input to unit RMS before projection. Reconstruction uses the pristine pooled vector. |
| `cache` | `True` | Reuse prepared text and frozen vectors through bounded hot tiers and a persistent disk store. A positive integer also caps hot entries; `False` disables every cache tier. |
| `store` | `None` | Choose a writable local cache directory. The default uses `RELFLOW_CACHE_DIR` when set, otherwise the platform cache directory. |
| `memory` | `None` | Budget the store's shared RAM cache payload in MiB. `None` uses 64 MiB; process overhead and the OS file cache are additional. |
| `resident` | `None` | Budget device cache tables and replacement workspace in MiB. CUDA defaults to one eighth of free memory, up to 512 MiB; other devices default to `0`. Set `0` to disable the device tier. |
| `objective` | `"l2"` | Choose `"l1"` or `"l2"` error for a reconstruction objective. |
| `jitter` | `rf.Jitter()` | Perturb pooled training representations after pristine frozen vectors have been cached; reconstruction targets stay unchanged. |

## Errors raised

| When | Failure | What to check |
| --- | --- | --- |
| Missing optional dependencies or unavailable encoder assets | Field construction or encoder loading fails. | Install the text extra and provision the selected encoder/tokenizer in the runtime environment. |
| An encoder without the selected pooling output or required metadata | `ValueError` identifies the missing hidden size, token output, or pooler output. | Choose a compatible encoder and pooling mode. |
| Warming a field with `cache=False` | `ValueError`: caching must be enabled before warming. | Enable caching before calling `embedder.warm(strings)`. |

### Footguns

- **Expecting fitting to fine-tune the text encoder.** The [encoder is frozen](https://github.com/relflow/relflow/blob/a1d0be3e373cf6c183e4926f1bfcbef845f2f883/src/relflow/tensorfields/extensions/text.py#L130); relflow learns how its representations support your declared targets. Choose an encoder suited to your language and domain, then evaluate the downstream task. Text reconstruction does not generate a reply or completion.
- **Counting characters instead of tokens.** `max_length` bounds tokenized input, and [tokenization truncates longer strings](https://github.com/relflow/relflow/blob/a1d0be3e373cf6c183e4926f1bfcbef845f2f883/src/relflow/tensorfields/extensions/text_cache/context.py#L155). Check tokenized lengths so decisive information survives, and choose a limit supported by the encoder.
- **Treating cache budgets as the entire resource footprint.** `memory` bounds shared hot payloads and `resident` budgets device cache tables; encoder/model memory, process overhead, and the OS file cache are additional. Disk entries persist without a built-in size limit. Set appropriate budgets and manage the writable store separately; the [cache contract](https://github.com/relflow/relflow/blob/a1d0be3e373cf6c183e4926f1bfcbef845f2f883/src/relflow/tensorfields/extensions/text.py#L173) distinguishes these resources.
- **Assuming the saved model contains every text resource.** Frozen encoder weights are [excluded from the field's state dictionary](https://github.com/relflow/relflow/blob/a1d0be3e373cf6c183e4926f1bfcbef845f2f883/tests/tensorfields/extensions/test_text.py#L682), and cache contents are not checkpoint state. Provision the encoder and tokenizer in the prediction environment, make the selected store available for persistent reuse, then check loading and prediction there.
