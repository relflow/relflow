**What can the model learn, and under which conditions?** Find an experiment
by capability, inspect its recorded result, and open the full experiment for
its setup, controls, checks, and source.

A result describes the recorded task and revision. Both met and unmet checks
remain visible; declarations without a selected learning run carry no measured
claim.
