**State-of-the-art predictive modeling, with a comparison you can inspect.**
On the nine published RelArena tasks with more than one million training
examples, relflow beats TabPFN-3 on **9 of 9** and TabPFN-3.5 on **6 of 9**.

| Compared model | relflow wins | Compared tasks |
| --- | ---: | ---: |
| TabPFN-3 · API and local variants | **9** | 9 |
| TabPFN-3.5 · API and local variants | **6** | 9 |

These tasks cover Amazon, H&M, and Stack Exchange. Each has **1.36–5.49
million labeled training observations**; an observation can contain a
history of related records.

## Count the whole model

A retained Amazon item-lifetime-value model has **926,554 task-trained
parameters**. Counting its shared frozen text encoder gives a broader
picture:

| What is counted | Parameters |
| --- | ---: |
| relflow predictive network | **926,554** |
| One distinct frozen MiniLM text encoder | 22,713,728 |
| **relflow network + encoder** | **23,640,282** |
| TabPFN-3.5 base checkpoint | Approximately 220,000,000 |

The task-trained network has roughly **237 times fewer parameters** than
that checkpoint. Including its frozen encoder, the relflow model has about
**nine times fewer parameters overall**.

The [relflow count](/benchmarks/relflow-parameters-2026-11-10.json),
[TabPFN checkpoint record](/benchmarks/tabpfn-parameters-2026-11-10.json),
and [TabPFN-3.5 report](https://arxiv.org/html/2609.17895v1) preserve the
counting boundaries. Parameter counts measure weights; latency, memory,
and serving cost require measurements of their own.

## Read the comparison precisely

- The large-task threshold counts the original labeled training examples,
  rather than source-table rows or the combined training-and-validation refit.
- The full leaderboard uses Elo over tasks with seed 0. Models use its
  standardized tuning regime; systems may use their own tuning procedures.
- The parameter count comes from a retained research model whose recipe
  matches the published submission. A separate execution produced the
  leaderboard scores. Schema details and vocabulary state can affect size.
